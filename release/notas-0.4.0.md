**Todos los jugadores tienen que usar esta misma versión** (la 0.4.0 no se entiende con la 0.3.0, y ahora el juego te lo dice).

### Novedades
- **Reconexión:** si a alguien se le corta la conexión, su juego vuelve a conectar solo y aparece en la misma sala que el anfitrión, con los enemigos ya muertos quitados. También se puede entrar a mitad de una expedición.
- **Jefes compartidos:** el mismo jefe para todos, los golpes de cualquiera cuentan, y sus ataques (rocas, trampas, raíces…) se ven en todas las pantallas. Aún poco probado: si algo va raro, abre un *Issue*.
- **Disparos visibles para todos:** flechas, disparos y balas enemigas se ven en todas las pantallas, y las balas enemigas hacen daño a todos.
- **Dificultad según los jugadores** (F2, la elige el anfitrión): como un jugador, ajustada (por defecto) o difícil.
- **Mando:** L3 + R3 abre el menú cooperativo; cruceta, A y B para moverse por los menús; el código se elige con una ruleta.
- **Versiones:** si no tenéis la misma versión no os deja conectar y dice cuál tiene cada uno. El menú F2 avisa cuando sale una versión nueva.
- **Seguridad:** también se revisan los datos del piso que manda el anfitrión antes de usarlos.

### Instalar
Descarga `MoonlighterCoop-0.4.0.zip` (abajo), descomprímelo y abre `Instalar.bat`. Si tenías una versión anterior, instala esta encima.
